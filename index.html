DATA GOVERNANCE

How to read this dashboard

⌁
Freshness

Impact metrics are current to 03 Sep 2026 for 07 Aug–03 Sep. Licensing and adoption metrics are current to 02 Sep 2026 unless otherwise noted.

Cohort interpretation

Results are observational and cohort sizes vary materially. Phase 2 contains 2 users and Phase 3 contains 4; treat their metrics as directional.

Risk categories

A user may appear in multiple risk components. Component counts are non-additive and should not be reconciled to the 29-user total.

Correlation ≠ causation

Neither the code shipped association nor PR growth proves Copilot caused the observed outcome. Controlled comparison is needed before attribution.

ROI assumption

Source ROI calculations use a default $130,000 salary assumption that is not Hostinger-specific. Monetary ROI is therefore intentionally omitted.

Metric boundaries

Platform consumption values are a current snapshot and may not align to the impact cohort window. No cross-period inference is implied.
