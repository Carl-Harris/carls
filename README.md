# Hostinger GitHub Copilot Impact Dashboard

A dependency-free, responsive executive dashboard built from the verified Hostinger GitHub Copilot adoption and impact data supplied for September 2026.

## View locally

Open `index.html` directly in a browser, or serve the repository:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
